📌 Project Title

Product Store App (React Assignment 9)

📝 Short Description

The Product Store App is a React-based e-commerce-style application built as part of a training assignment. It allows users to browse products, view detailed product information by clecking over the product picture, and manage a shopping cart. there are two pages on this site Home page that customers can see the products and the Cart page that when you cleck on Add to Cart over a product it will go to the Cart page and you can check or manage them later. and another heden page which is product detail page and you can see this page if you cleck over the product on home page.  

The project demonstrates the use of modern React state management tools including Context API with useReducer, Redux Toolkit, and React Query.
